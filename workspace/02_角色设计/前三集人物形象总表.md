# 前三集人物形象总表

这份文件只服务前三集样片。

前三集的重点不是把整部剧所有人物都设计出来，而是先把开头三集会反复出现、需要保持长相一致的人物定下来。这样后面做画面时，人物不会一集一个样。

## 这次真正需要单独设计的人物

前三集真正需要单独设计的人物有五个。

| 人物 | 为什么要单独设计 |
| --- | --- |
| 黄简 | 他是前三集的主角，几乎每一集都围绕他展开。他从死人堆里爬出来，在死牢里护住老者，又靠换尸逃出去，所以他的脸、身体、衣服变化都必须稳定。 |
| 老者 | 他是黄简逃出去的关键人物。第一集他临终，第二集回忆里他教过黄简，第二集和第三集又被黄简用来完成换尸，所以他的样子和衣物必须清楚。 |
| 年轻狱卒 | 他是前三集里最直接欺负黄简的人。他粗躁、嘴硬、怕晦气，第三集发现“鬼剃头”时反应很大，所以需要有固定形象。 |
| 老狱卒 | 他和年轻狱卒经常一起出现，但性格完全不同。他更冷、更老练，也更怕麻烦。两名狱卒必须一眼能分清。 |
| 陈新豪 | 他在第三集后半出现，是新狱监，也是刺史家的亲戚。他一出现，就让观众知道危险升级了，所以需要单独设计。 |

## 只需要做成模板的人物和物件

追兵和乱葬岗尸体不需要固定脸。

追兵主要用火把、脚步声、喊声和远处人影来表现。他们的作用是把黄简逼回乱葬岗边，不是让观众记住某一个追兵。

乱葬岗尸体也不需要当成角色来画。它们更像环境和道具。画面里要有破草席、破旧衣服、湿泥、露出的手脚局部。第三集有一具无人认领的尸体，身上有破旧外袍和腰带，黄简会从那里找到换装机会。

## 设计顺序

建议先设计黄简。黄简最复杂，因为前三集里他至少有五种状态。

第二个设计老者。老者和黄简之间的关系要能看出来，观众要相信黄简愿意冒险护住他的尸体。

第三个设计年轻狱卒和老狱卒。两个人都在死牢里做事，但不能长得像同一个人换了年龄。

第四个设计陈新豪。他出场晚，但他代表更高一层的权力，所以要和普通狱卒明显不一样。

最后再做追兵和乱葬岗尸体。它们只需要统一风格，不需要做成固定人物。

## 前三集要特别注意的东西

旧灰帽、破草席、磨薄石片、黄简的黑发、老者的灰白发、黄简的囚衣、老者的旧衣、乱葬岗尸体身上的破旧外袍，这些东西要画清楚。

前三集的换尸逻辑靠这些东西成立。如果这些东西前后不一致，观众会看不懂黄简是怎么逃出去的。
