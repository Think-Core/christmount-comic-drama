# 前三集场景设计总表

这份文件只服务前三集样片。

前三集的场景不需要按每一个镜头单独设计。更合适的做法，是先把会反复出现、必须保持一致的地方设计清楚。这样后面做画面时，观众能知道人物从哪里来，又去了哪里。

## 这次真正需要固定设计的场景

前三集真正需要固定设计的大场景有六个。

| 场景 | 出现在哪些地方 | 为什么要单独设计 |
| --- | --- | --- |
| 乱葬岗 | 第一集开头，第三集后半 | 黄简第一次从死人堆里爬出来就在这里。第三集他又被当成尸体丢回这里，所以这个地方必须前后一致。 |
| 死牢牢房 | 第一集、第二集、第三集 | 老者临终、黄简护住老者、守灵、换尸、鬼剃头都在这里。它是前三集最重要的内景。 |
| 死牢走廊和牢门 | 第一集、第二集、第三集 | 狱卒从这里来，火把光、油灯光、钥匙声、脚步声也从这里进入牢房。它要和牢房连得上。 |
| 牢外山路和运尸路 | 第三集 | 黄简被草席包着，由狱卒抬出死牢，放上板车，再被推往乱葬岗。这里负责连接死牢和乱葬岗。 |
| 狱监值房 | 第三集后半 | 陈新豪在这里第一次出场。这个地方要比死牢干净一些，但仍然要冷，不能像明亮舒服的官衙。 |
| 乱葬岗边旧路和荒坡 | 第三集结尾 | 黄简想往兴城方向走，却被追兵火把逼回来。他摔到尸堆边，发现可以拿来换装的破旧外袍。 |

## 还要统一的小环境和小物件

除了六个大场景，还要统一四类细节。

| 细节 | 为什么要统一 |
| --- | --- |
| 破草席 | 黄简从草席里爬出来，也靠草席被抬出死牢。草席如果前后不一样，换尸就会看不懂。 |
| 稻草堆和牢房墙角 | 老者躺在这里，黄简退到这里，老者后来也被伪装成“黄简”坐在这里。 |
| 小窗月光和火把油灯 | 前三集大部分画面都很暗，必须用这些光让观众看清人物和动作。 |
| 板车、铁锁、钥匙 | 第三集运尸、开门、追查都要用到这些东西。它们不用很抢眼，但要前后一致。 |

## 这次不整理哪些场景

这次不整理青松庙。

这次不整理兴城。

这次不整理陈汉客栈。

这次也不整理后面会出现的商铺、林宅、刺史府大场面。

这些地方不是前三集样片要做出来的重点。现在先把前三集能看懂、能连起来的地方做好。

## 场景设计顺序

建议先设计死牢牢房和死牢走廊。前三集大部分画面都在这两个地方。

然后设计乱葬岗。乱葬岗是开场大画面，也会在第三集回来一次。

再设计牢外山路、狱监值房、乱葬岗边旧路和荒坡。

最后统一破草席、稻草、小窗月光、板车、铁锁和钥匙这些细节。
